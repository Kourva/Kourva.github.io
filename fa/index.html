Kourva

من سهند فرازمهر هستم و آنلاین با نام کوروا شناخته می‌شوم. شش سال در توسعه و نه سال لینوکس به‌عنوان سیستم‌عامل اصلی‌ام. با پایتون خالص، ربات‌های تلگرام، اپ‌های اندروید با Kivy و Flet و ابزارهای مبتنی بر API که نیازهای خودم را برطرف می‌کردند شروع کردم. جنگو و کمی HTML مرا به وب کشاند.

سه سال گذشته فول‌استک بوده: Vue و Laravel در کنار Odoo، عملاً دو کار همزمان. یک سال و نیم گذشته روی Vue و Nuxt تمرکز کرده‌ام و در تیمی کوچک با یک توسعه‌دهنده بک‌اند محصول می‌دهم.

ادعا نمی‌کنم همه‌جای PHP، JS یا TS را می‌دانم. آن‌قدر می‌دانم که چیزهای واقعی بسازم و همین مرا تا اینجا آورده است.

اختیاری تا وقتی ضروری شود. اگر کس دیگری کد را بخواند، README می‌گیرد که چرایی را توضیح می‌دهد.

DevOps

کمک‌کننده‌های کوچک که اصطکاک را برمی‌دارند: اسکریپت‌های دیپلوی، Makefile، راه‌اندازی با یک دستور. مدیریت باید خسته‌کننده باشد.

وضعیت

چیزهایی که ساخته‌ام

پروژه‌های واقعی، نه دمو. پلتفرم‌های چنداپلیکیشنی، ابزارهای داخلی و سیستم‌های فول‌استک — بعضی عمومی، بعضی پشت درهای بسته. همه برای اجرا ساخته شده‌اند، نه برای نمایش.

کافه‌ای برای جلسات

یک سایت کافهٔ معمولی نیست. این حول مشاوران و کارگزارانی طراحی شده که به مکانی آرام برای ملاقات با مشتریان، رزرو میز، سفارش از منو و شروع کار نیاز دارند. منطق کامل رستوران پشت یک فرانت رزرو-محور.

  • ادمین کافه محصولات خودش را تعریف می‌کند: چای، غذا، منوی کامل
  • رزرو میز با بسته‌ها و محصولات ترکیبی
  • مشاوران و کارگزاران فضا را برای ملاقات با مشتری رزرو می‌کنند
  • ادمین اصلی منابع و محتوای سایت را کنترل می‌کند
  • ادمین دو سطحی: صاحب کافه و صاحب پلتفرم
  • جریان کامل رستوران، نه یک صفحهٔ منوی ثابت

سیستم صلاحیت حرفه‌ای

پلتفرمی برای بازرسان، ارزیابان و حسابرسان تا آمادگی حرفه‌ای خود را اثبات کنند. کاربران از صفر رزومه می‌سازند، نقش‌های دلخواه را انتخاب می‌کنند و سیستم دقیقاً می‌گوید چه چیزی برای رسیدن به آن کم دارند.

  • رزومه‌ساز داخلی: مهارت‌ها، دانش، توانایی‌ها، رفتارها
  • انتخاب شغل و علاقه‌مندی‌ها
  • تحلیل خودکار شکاف برای هر مسیر شغلی
  • ارزیابی‌ها، دوره‌ها، پادکست‌ها، مقالات را پیشنهاد می‌دهد
  • به کاربران می‌گوید چه بیاموزند و به چه برسند تا آماده باشند
  • رابط مدرن و مینیمال

چیزهایی که لمس کرده‌ام

فهرست مهارت نیست. فقط ابزارها و ایده‌هایی که با آن‌ها برخورد داشته‌ام، بعضی عمیق و بعضی فقط در حد دانستن اینکه چیست.

BACKEND

Django

به‌اندازهٔ ساخت اپ‌های واقعی. دیگر ابزار روزانه‌ام نیست.

MOBILE

Kivy / Flet

چند اپ اندروید با هر دو منتشر کردم. Flet سبک‌تر بود.

WEB

HTML / CSS / JS / TS

در مرورگر راحتم. TS وقتی پروژه لیاقتش را دارد.

BOTS

Telegram / telebot / PTB

ده‌ها ربات در طول سال‌ها. بعضی هنوز در حال اجرا هستند.

DATA

SQL / SQLite

می‌توانم اسکیما را بخوانم و کوئری بنویسم. DBA نیستم.

SYSTEMS

Linux Admin

تا chroot، systemd و بخش‌های زشتش. سیستم‌عامل روزانه.

SECURITY

XSS / SQLi / IDOR / DDoS

می‌دانم چیستند و چطور از آن‌ها دوری کنم. پنتستر نیستم.

INFRA

Load Balancing

فقط تئوری. هنوز در پروداکشن اجرا نکرده‌ام.
