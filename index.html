Process

How I Work

Eight main rules I follow on every project. Unless you don't want them!

Style

Minimal and up to date. Nothing heavy, nothing dated. Every project gets its own look, not a recycled template.

Motion

Light animation with weight. GSAP for the moments that matter, plain CSS everywhere else. Never decoration, always signal.

Security

Encryption and security are not features, they are defaults. I treat every input as hostile until proven otherwise.

Structure

Clean folders, clean assets. If a new dev cannot find where things live in 30 seconds, the structure failed.

Version Control

Git from the first commit. Small branches, readable history, no force-pushes to shared branches. Ever.

Docs

Optional until it is not. If someone else will read the code, they get a README that explains the why.

DevOps

Small helpers that remove friction, deploy scripts, Makefiles, one-command setups. Management should be boring.

State

Dynamic where it counts. More control over loading, error, empty, and success states than most apps bother with.
